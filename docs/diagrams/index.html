1 · Process flow

The care loop, from hospital letter to the next plan

One row per person. The loop in blue is the point of the product: what the patient does at home reaches the physio, and the physio's change reaches the patient's next session.

2 · Architecture

Browser, Cloud Run, and the Google services behind it

The browser never touches the database. Everything goes through the Cloud Run server, except the live voice, which streams straight to Gemini with a one-use token the server made.

3 · Technologies

What Langkah is built with

Green tiles are Google services. One TypeScript codebase: the same rules and data model run in the browser and on the server.
